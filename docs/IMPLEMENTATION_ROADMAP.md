# Implementation roadmap

## M0 — architecture foundation

Documentation, conventions, environment template, reference-artifact preservation, migration scaffold, source-adapter contracts, and rule governance only.

**Definition of done:** no application feature, patient data, production rule, clinical approval, or Gemini flow exists.

## M1-M10

1. M1: Next.js shell, reference UX translation, design system, routing, i18n scaffolding.
2. M2: Auth, profiles, patient-professional connection workflow, RLS.
3. M3: Prescription/manual medication capture, review, confirmation, and normalization.
4. M4: Medication schedules, dose events, adherence.
5. M5: Medical-source adapters/cache and rule-governance user workflow.
6. M6: Food capture, components, deterministic temporal assessment, evidence UI.
7. M7: Safety reporting and professional review.
8. M8: Tool-based AI explanation and professional insights.
9. M9: Preferences, in-app reminders, accessibility, security hardening.
10. M10: E2E verification, deployment, production readiness review.

No milestone begins until the preceding definition of done is met.
